# World Happiness Analysis

This project performs exploratory data analysis on the World Happiness dataset using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis
- Data Cleaning
- Exploratory Data Analysis
- Happiness Score analysis
- GDP analysis
- Social Support analysis
- Healthy Life Expectancy analysis
- Freedom analysis
- Correlation Analysis

## Files
- World_Happiness_Analysis.ipynb – Google Colab notebook
- World_Happiness_Dataset.csv – Dataset
